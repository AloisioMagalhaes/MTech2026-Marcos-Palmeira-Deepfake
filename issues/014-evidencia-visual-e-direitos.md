# Issue 014 — Evidência visual e direitos de uso

## Objetivo

Apresentar fatos reais com imagens verificáveis sem violar direitos autorais, direito de imagem ou LGPD.

## Critérios de aceite

- [x] fontes jornalísticas confiáveis vinculadas no HTML;
- [x] licença Creative Commons registrada para ilustração conceitual;
- [x] nenhuma foto jornalística protegida copiada sem autorização;
- [x] cada visual rotulado como fonte jornalística, ilustração ou diagrama autoral;
- [x] prompt e decisão de uso documentados;
- [x] diagramas factuais incorporados aos slides;
- [ ] obter autorização documental caso a foto ou vídeo original seja indispensável.
