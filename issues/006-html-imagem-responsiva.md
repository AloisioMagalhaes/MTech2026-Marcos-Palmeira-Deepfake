# Exibir JPGs com HTML responsivo e acessível

## Objetivo
Substituir o conteúdo textual complexo por uma galeria HTML5 de imagens JPG, preservando navegação, descrição alternativa e escala responsiva.

## Critérios de aceite
- HTML contém apenas layout, controles e referências às imagens.
- `object-fit: contain`, largura máxima e proporção 16:9.
- Navegação por teclado e alt text para cada slide.
