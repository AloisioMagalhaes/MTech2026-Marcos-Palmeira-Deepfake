# Plano de gráficos por slide

## Prompt revisado

> Para cada slide, associe o conteúdo a um gráfico ou diagrama que torne a relação visualmente explícita. Use gráfico quantitativo somente quando houver dado publicado, unidade, população, período e fonte verificável. Na ausência desses dados, use visualização qualitativa: fluxo, linha do tempo, matriz, cadeia causal, mapa de riscos ou checklist. Rotule o visual como diagrama autoral e mantenha fato, indício, hipótese e limitação separados. Preserve o fundo azul, cartões de alto contraste, proporção 16:9, acessibilidade e LGPD.

## Implementação

| Slides | Visual | Base da relação |
|---|---|---|
| 2–3 | cadeia de três etapas | imagem/voz → oferta → usuário; vídeo prévio → voz sintética → anúncio |
| 4 | linha do processo | origem → edição → circulação → checagem |
| 5–6 | cadeia causal | relato → circulação → impacto; IA → identidade → incentivo |
| 7 | mapa qualitativo de riscos | conteúdo → confiança → dano |
| 8 | matriz conceitual | conceito → evidência → limite |
| 9 | fluxo de resposta | pausar → confirmar → denunciar |
| 10 | mapa de comunicação | público → mensagem → canal |
| 12 | mapa de impactos | econômico, informacional e confiança |

Nenhum número, porcentagem, ranking ou tendência quantitativa foi criado sem fonte. Os visuais são sínteses autorais dos textos já documentados.
